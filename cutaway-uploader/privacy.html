Effective October 20, 2026. This policy covers Cutaway Facts Uploader, a private desktop script run only by the operator of Cutaway Facts.

Information it handles

  • From TikTok: the account’s open_id, access token, refresh token, granted scopes and token expiry times, plus basic profile information allowed by user.info.basic if requested.
  • Videos: only Cutaway Facts videos made by the operator, read from the operator’s Mac and sent to TikTok.

Where it is stored

Tokens and the app’s client credentials are saved only in a file on the operator’s Mac readable by the operator alone. There is no server or database. Nothing is sent anywhere except to TikTok’s own API (open.tiktokapis.com and the upload address TikTok returns).

Sharing

No information is sold or shared with third parties. No ads, analytics or tracking are used.

Deleting

Deleting the token file on the Mac removes all stored data. Access can also be removed at any time in TikTok’s app permission settings, or the operator can revoke the token through TikTok’s revoke endpoint. Drafts and posts on TikTok are managed in the TikTok app.

  • 다루는 정보: TikTok 계정의 open_id, 액세스·리프레시 토큰, 허용 범위와 만료 시각(요청 시 user.info.basic 기본 프로필). 영상은 운영자가 만든 Cutaway Facts 영상만 보냅니다.
  • 저장 위치: 토큰과 앱 자격 정보는 운영자 Mac의 운영자 전용 파일에만 저장합니다. 서버·데이터베이스가 없고 TikTok API 외에는 아무 곳에도 보내지 않습니다.
  • 공유: 제3자에게 팔거나 공유하지 않으며 광고·분석·추적을 쓰지 않습니다.
