Cutaway Facts Uploader is a private desktop script used by the operator of the short-video channel Cutaway Facts. It is not a public app and has no other users.

What it does

  • Signs in to the operator’s own TikTok account with TikTok Login Kit (scopes user.info.basic and video.upload).
  • Sends a finished Cutaway Facts video, made by the operator, to that account’s TikTok inbox as a draft using the Content Posting API (upload mode).
  • It does not post directly. The operator opens the TikTok app, reviews the draft, adds the caption and AI-generated content label, and publishes it.

It runs only on the operator’s Mac. There is no server, website login or user data collection.

한국어

Cutaway Facts Uploader는 숏폼 채널 Cutaway Facts 운영자가 쓰는 개인용 데스크톱 스크립트입니다. 공개 앱이 아니며 다른 이용자는 없습니다. TikTok Login Kit으로 운영자 본인 계정에 로그인하고, 운영자가 만든 영상을 Content Posting API(업로드 모드)로 그 계정의 TikTok 받은편지함에 초안으로 보냅니다. 직접 게시하지 않으며, 운영자가 TikTok 앱에서 초안을 확인하고 캡션과 AI 생성 콘텐츠 표시를 넣은 뒤 게시합니다. 운영자의 Mac에서만 실행되며 서버·웹 로그인·이용자 정보 수집이 없습니다.
